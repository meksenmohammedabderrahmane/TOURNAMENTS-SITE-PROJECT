# N1 Arena , Competitive Fortnite Tournament Platform

N1 Arena is a premium esports tournament platform built for competitive Fortnite players, designed to provide a smooth, fair, and professional tournament experience.

The platform allows players to register via Discord, join tournaments, compete in structured brackets, report match results, and track their performance — all within a modern and responsive interface.

This project was built with a strong focus on real-world usability, reliability, and scalability.

Live site:
https://n1arenaclient.vercel.app/

---

## 🚀 Project Vision

The goal of N1 Arena is to create a community-driven tournament ecosystem where players can compete in skill-based competitions without gambling mechanics.

The platform emphasizes:

- Fair play
- Clean user experience
- Transparent match reporting
- Strong admin oversight
- Competitive integrity

---

## 🏗 Architecture Overview

Frontend:
- Deployed on Vercel
- Modern responsive UI
- Real-time tournament views

Backend:
- Hosted on Render
- Handles authentication, tournament logic, match flow, and admin actions

Database:
- PostgreSQL (via Supabase)
- Stores users, tournaments, teams, matches, and activity logs

Authentication:
- Discord OAuth for seamless login

---

## ⚙️ Core Features

### 🔐 Authentication
- Login via Discord
- Automatic account creation
- Player profile management

### 🏆 Tournament System
- Scheduled tournaments
- Registration before start time
- Automatic bracket generation
- Live bracket updates
- Match progression tracking

### 👥 Team Support
- 1v1 and 2v2 modes
- Team registration
- Split or covered entry logic
- Consent-based participation

### 🎮 Match Reporting
- Players report win or loss
- Confirmation system
- Dispute handling via admin

### 💰 Balance System (Manual)
- Deposit and withdraw handled through Discord coordination
- No automated payments or gambling

### 🛠 Admin Panel
- Create and manage tournaments
- Monitor matches
- Resolve disputes
- Manage players and balances
- View activity logs
